# Map camera fonts

`RRMapSansSC-Medium.ttf` and `RRMapSansSC-Bold.ttf` are subsets of
[Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)
(weights 500 and 700), renamed as the SIL Open Font License requires for
modified versions. They are used only to draw room names and labels on the
map camera's picture.

- Medium: GB2312 levels 1 and 2 (6,763 characters), ASCII, common symbols.
- Bold: GB2312 level 1 (3,755 characters), ASCII, common symbols.
